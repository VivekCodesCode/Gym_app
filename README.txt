BODY TOWN GYM WEBSITE — SOURCE PROJECT

Folder structure:
- index.html       Main website markup
- css/style.css    All styling and responsive layout
- js/script.js     Page navigation and Web3Forms submission logic
- assets/          Actual Body Town Gym photos

HOW TO RUN:
1. Extract this ZIP into a folder.
2. Keep the folder structure unchanged.
3. Open index.html in Chrome.

CONTACT FORM:
The form uses Web3Forms and the access key configured in index.html.
Submissions are sent to the recipient configured for that Web3Forms access key.
If the recipient email or key changes, update the hidden access_key field in index.html.

IMPORTANT:
Keep the assets folder beside index.html. Do not move or rename the image files unless you also update their paths in index.html.
Google Fonts are loaded online; system fallbacks are included.
